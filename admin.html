Connect your GitHub repo

This isn't a hosted login — there's no server here. You're giving your browser a personal access token so it can write to your own repo on your behalf. The token is stored only in this browser's local storage and is sent only to api.github.com. Use a fine-grained token scoped to just this one repository, with "Contents" permission set to Read and write. Create one at github.com/settings/personal-access-tokens/new.
