Privacy Policy

Last updated: [add date when you publish this]

Memory Match is built to work with as little data collection as possible. This page explains exactly what the app stores, what it sends over the network, and what it doesn't do.

What's stored on your device

Everything the app needs to run lives in a local database on your phone. Nothing here is sent to us or anyone else:

  • The card library (titles, images, descriptions, and how often each card should appear).
  • Game history — scores, flip counts, and match counts from past games.
  • The admin password, stored as a one-way hash, never as plain text.
  • App settings, like the card-update address and the WhatsApp ordering number.

None of this requires an account, an email address, or a name. If you uninstall the app, this data is removed with it.

What the app sends over the network

  • Card updates. Every so often, the app checks a public list of card images we publish and downloads any new or changed ones. This is a standard file download — it doesn't include anything about you or your device.
  • WhatsApp ordering. Tapping "Order on WhatsApp" opens the WhatsApp app with a pre-filled message. From that point on, the conversation is handled by WhatsApp under its own privacy policy — Memory Match doesn't see or store that message.
  • Anonymous play analytics (only if the shop admin has turned it on). Some installs of this app are configured to record, for each card flip or match: which card, whether it was a flip or a match, a coarse region (state/province-level, guessed from your network connection via a public IP-geolocation lookup — never GPS, never a location permission prompt), and a generic device model string (e.g. "Pixel 7"). There is no name, account, advertising ID, or any other identifier attached to this — it cannot be used to identify you personally, only to show the admin aggregate totals like "how many times was this card flipped" or "how many flips came from this region." This can be turned off per install by the admin; if it's off, none of this is ever sent.

What we don't do

  • No account creation or sign-in.
  • No advertising or ad tracking.
  • No GPS or precise location — ever.
  • No third-party analytics SDK embedded in the app — the optional analytics above is a small, self-hosted endpoint the admin controls, not a third-party tracking service.
  • No selling or sharing of any information.

The admin area

A hidden admin screen lets whoever runs the deck add, edit, or remove cards, set visibility limits, and view play statistics. It's protected by a password stored only on that device. Local statistics are calculated entirely from that device's own game history; if analytics is turned on (see above), the admin can also see aggregate, anonymous totals gathered across every device.

Children's use

Memory Match doesn't collect personal information from anyone, including children. The ordering feature simply opens WhatsApp with a pre-written message and is intended for use by an adult on the shopper's behalf.

Changes to this policy

If how the app handles data ever changes, we'll update this page and the "last updated" date above.
